# 偏好改造预览

## 文件位置
`travel-agent/scripts/preview-pref-route.html`

## 用法
直接双击打开，或拖到浏览器；也可通过 WorkBuddy 内置浏览器打开预览面板。

## 内含 4 个场景
- 场景 A：公交跨城 1986km + 「最快到达」偏好 → 顶部「⚡ 最快到达 · 已按最快到达排序」+「🛬 跨城出行」+ 航班估算卡片紫边
- 场景 B：驾车 580km + 「最省钱」 → 「💰 最省钱 · 已按票价/油费升序排序」
- 场景 C：驾车 200km + 「躲避拥堵」 → 「🛣️ 躲避拥堵 · 已采用躲避拥堵/少换乘策略」
- 场景 D：默认推荐 → 「🧭 智能推荐 · 按高德默认排序」

## 数据是模拟的
HTML 里的 `data-i` / 距离 / 时间是 preview-pref.js 跑出来的真实 `buildRouteHTML` 输出。
线上真实数据会替换这些，但样式 / 徽章 / 卡片结构完全一致。

## 改造前 vs 改造后
| 维度 | 改造前 | 改造后 |
|---|---|---|
| 偏好传给高德 | ❌ | ✅ DrivingPolicy / Transfer policy 都透传 |
| 卡片排序 | 固定 | fastest 按耗时 / cheapest 按票价 / 其他按策略类型 |
| 第一张卡片 tag | 「推荐」 | ⚡ 最快 / 💰 最省钱 / 🛣️ 躲避拥堵 / 🧭 智能推荐 |
| 顶部徽章 | 无 | mode-chip + pref-badge + 跨城标签 |
| 跨城 (>800km) | 易幻觉（郴柏相） | ✈ 航班 / 🚄 高铁估算双卡替代 |
